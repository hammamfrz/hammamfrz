### What I work on
- **Real-time systems**: nationwide position tracking with Socket.io, MongoDB and geofencing; a Go chat service on WebSocket with Redis Pub/Sub fan-out
- **Go service platform**: dashboard and mobile APIs with chi + huma (OpenAPI), sqlc on pgx with PostgreSQL primary/replica routing
- **High-volume pipelines**: millions of daily reports through RabbitMQ consumers, PgCat pooling and Redis caching
- **Architecture**: led an Express.js → NestJS + Prisma migration using DDD bounded contexts and CQRS
- **Delivery**: GitHub Actions → Artifact Registry → GCP, with a Go deploy agent rolling out Docker Compose stacks
